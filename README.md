## 项目概述
本项目是一个为口腔医院设计的室内导航小程序，旨在帮助患者快速找到目标科室。小程序基于微信小程序平台开发，提供科室选择、导航路径规划和实时定位功能。

## 项目功能
1. **AI智能分诊**：
   - 基于DeepSeek AI的智能对话问诊系统
   - 根据症状描述自动推荐合适的口腔科室
   - 提供详细的诊断依据和医疗建议
   - 一键直达推荐科室的导航页面

2. **科室选择**：
   - 患者可通过下拉菜单选择目标科室（如正畸科、放射科等）。
   - 支持动态加载科室列表。

3. **导航路径规划**：
   - 根据患者选择的科室，生成最优导航路径。
   - 提供分步导航指引。

4. **实时定位**：
   - 使用微信小程序的定位功能，获取患者当前位置。
   - 结合医院室内地图，提供精准导航。

5. **个人资料管理**：
   - 微信账号登录和用户信息管理
   - 病历记录和AI诊断历史存储
   - 健康状态跟踪和提醒

6. **病历详情展示**：
   - 完整的病历详情页面展示，替代简单弹窗
   - 支持就诊时间、科室、医生、主诉、诊断结果、治疗经过、用药信息、复诊信息等详细信息展示
   - 病历信息复制和分享功能
   - 模拟医院系统数据集成

6. **数据提示**：
   - 当目标科室暂无导航数据时，显示提示信息。

## 程序结构
1. **页面结构**：
   - `pages/index/index`：首页入口。
   - `pages/navigation/navigation`：核心导航页面，包含科室选择和路径规划。
   - `pages/map/map`：地图展示页面。
   - `pages/science/science`：科普知识页面。

2. **配置文件**：
   - `app.json`：全局配置，包括页面路径、窗口样式和权限设置。
   - `navigationConfig.js`：科室导航配置，定义科室信息和路径数据。

3. **新增页面**：
   - `pages/profile/medical-record-detail/medical-record-detail`：病历详情页面
   - 包含完整的病历信息展示、复制和分享功能

4. **核心逻辑**：
   - `navigation.js`：处理科室选择、路径规划和导航逻辑。
   - `map.js`：地图相关功能实现。
   - `profile.js`：个人资料和病历信息管理逻辑。

## 使用说明
1. 打开微信小程序，进入首页。
2. 选择目标科室，点击“开始导航”。
3. 根据指引完成路径规划。
